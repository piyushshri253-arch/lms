SECURITY BOUNDARY

Strict Dual-Portal Boundary Enforcement

Complete isolation between the Student Storefront and Administrative Command Center

Student Portal (/login & /register)

  • Public registration is strictly hardcoded to role STUDENT.
  • Admins & Super Admins attempting to login here receive HTTP 403 Forbidden.
  • Shows clear guidance: "Platform Staff? Use Admin Portal →".
  • Students browse courses, purchase in INR (₹), and access their learning cockpit.

Admin Backend (/admin/login)

  • Restricted strictly to roles SUPER_ADMIN and ADMIN.
  • Students attempting to login here receive HTTP 403 Forbidden.
  • Zero public discoverability — hidden cockpit for business operations.
  • Audit logs, course approvals, staff role assignment, and financial analytics.

ARCHITECTURE

Full-Stack Technology Architecture

Built with enterprise modern web standards for high performance and scalability

Frontend

Next.js 14 App Router, React 18 Server & Client Components, Tailwind CSS, Lucide React icons, and accessible Radix primitives.

API & Auth

Next.js Route Handlers, NextAuth.js JWT authentication, bcrypt password hashing, and cookie-based role session verification.

Database & Media

Prisma ORM with PostgreSQL database, relational integrity constraints, and scalable cloud storage for course media assets.
